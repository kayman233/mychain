## 🔨 Компиляция

### Локально (требует BasicTeX или MacTeX)

```bash
# Убедитесь что BasicTeX установлен
brew install basictex  # если еще не установлен

# Установите поддержку русского языка (один раз)
sudo /Library/TeX/texbin/tlmgr update --self
sudo /Library/TeX/texbin/tlmgr install collection-langcyrillic

# Компилируйте (дважды для корректных ссылок)
export PATH="/Library/TeX/texbin:$PATH"
pdflatex -interaction=nonstopmode paper.tex
pdflatex -interaction=nonstopmode paper.tex
```

### Через Overleaf

1. Загрузите все файлы из этой папки в Overleaf
2. Установите основной документ: `paper.tex`
3. Компилятор: `pdfLaTeX`

## 📋 Правила форматирования

См. `/docs/paper-drafts/formatting_rules.md` для правил выделения текста жирным шрифтом.

**Основные правила:**
- Системы (Vault12, Grid+, etc.) выделяются **жирным** при первом описании
- Технологии (Ethereum, Cosmos, SSS) выделяются при первом значимом упоминании
- Технические термины (`EntryPoint`, `GUARDIANS`) выделяются `моноширинным`
